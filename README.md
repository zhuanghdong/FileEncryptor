# 🔐 文件加密器

一个简洁的文件加密/解密工具，使用 AES-256-GCM 加密算法。

## ✨ 功能特性

- 🔒 **AES-256-GCM 加密** - 军事级加密，安全可靠
- 🔑 **PBKDF2 密钥派生** - 100,000 次迭代，防暴力破解
- 👁️ **显示/隐藏密码** - 方便确认输入
- 📊 **进度条显示** - 大文件处理时显示进度
- 🖱️ **拖拽文件支持** - 直接拖文件到窗口
- 📁 **自动输出到桌面** - 默认输出位置为桌面

## 🚀 快速开始

### 方式一：直接运行（需要 Python）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行程序
python main.py
```

### 方式二：打包成 EXE

```bash
# 双击运行 build.bat，等待打包完成
# 生成的 exe 在 dist 文件夹中
```

## 📖 使用说明

1. **选择文件** - 点击"浏览"或拖拽文件到窗口
2. **设置输出位置** - 默认桌面，可手动更改
3. **输入密码** - 至少 6 位
4. **点击加密/解密**

### 加密文件
- 选择任意文件 → 输入密码 → 点击"加密文件"
- 生成 `.enc` 后缀的加密文件

### 解密文件
- 选择 `.enc` 文件 → 输入相同密码 → 点击"解密文件"
- 恢复原始文件

## ⚠️ 注意事项

1. **密码请牢记** - 忘记密码将无法解密文件
2. **密码区分大小写**
3. **不要修改加密文件** - 任何修改都会导致解密失败

## 🔧 技术细节

| 项目 | 说明 |
|------|------|
| 加密算法 | AES-256-GCM |
| 密钥派生 | PBKDF2-SHA256 (100,000 iterations) |
| 盐值长度 | 16 bytes |
| Nonce 长度 | 12 bytes |
| GUI 框架 | tkinter |
| 拖拽支持 | tkinterdnd2 |
